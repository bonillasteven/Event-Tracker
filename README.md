# 📅 Event Tracker

A command-line Event Tracker application built with Python that allows users to organize and manage personal events. The application provides a simple menu-driven interface where users can add, edit, remove, search, and view events. Event data is automatically saved using JSON, allowing information to persist even after the program is closed.

---

## 🚀 Features

- ➕ Add new events
- ✏️ Edit existing events
- ❌ Remove events
- 🔍 Search events by title
- 📅 View all events sorted by date
- 💾 Automatically save events using JSON
- 📂 Load saved events when the application starts
- 🎨 Colorized terminal interface for improved readability
- 📝 User-friendly menu system

## ▶️ How to Run

1. Clone the repository

```bash
git clone https://github.com/bonillasteven/Event-Tracker.git
```

2. Navigate to the project folder

```bash
cd Event-Tracker
```

3. Run the program

```bash
python event_tracker.py
```
