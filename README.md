# Event-Tracker
A command-line Event Tracker built with Python that helps users organize and manage events. Users can create, edit, search, remove, and view events sorted by date through an easy-to-use terminal interface.

## Features

- Add new events
- Edit existing events
- Remove events
- Search for events by title
- View all events
- Sort events by date
- Colorized command-line output
- Modular Python program structure
