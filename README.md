# 📅 Event Tracker

A command-line Event Tracker built with Python that helps users organize and manage events. Users can create, edit, search, remove, and view events sorted by date through an easy-to-use terminal interface.

---

## Features

- Add new events
- Edit existing events
- Remove events
- Search for events by title
- View all events
- Sort events by date
- Colorized command-line output
- Modular Python program structure

---

## Technologies Used

- Python 3
- `datetime` module
- ANSI Escape Codes (Terminal Colors)
- Command-Line Interface (CLI)

---

## How to Run

### Prerequisites

- Python 3.x installed

### Installation

1. Clone the repository:

```bash
git clone https://github.com/bonillasteven/event-tracker.git
```

2. Navigate to the project folder:

```bash
cd event-tracker
```

3. Run the application:

```bash
python event_tracker.py
```
